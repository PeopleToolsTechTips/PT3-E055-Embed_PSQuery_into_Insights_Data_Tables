#### Add PSQuery Links to your Insights Data Tables.

This is the PeopleTools and Insights Tools objects used in the video demonstration and Web Posting

Insights Data Tables show the detailed data behind the visualizations in a spreadsheet LIKE format.  They respond to the selection and filtering with the rest of the dashboard because they themselves are visualizations just like a Bar or Pie chart.

But data tables are not spreadsheets and there are specific limits on real estate and memory.  We can’t expect unlimited rows and columns.

So when the users want more columns, give them a keyed link to a PSQuery report
